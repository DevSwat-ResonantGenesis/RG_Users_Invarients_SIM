State Physics - Complete Guide

What is State Physics?

State Physics is a constraint-governed state-space universe visualizer that models complex systems (blockchain networks, user ecosystems, AI agent swarms) as a physics simulation.

  • Nodes = Entities (users, agents, services, contracts, states)
  • Edges = Relationships (transactions, trust links, ownership)
  • Physics = Forces that govern how entities interact and evolve over time

Purpose & Why It Exists

State Physics exists to visualize and validate complex distributed systems by treating them as physical universes with conservation laws:

  • Detect Anomalies - See when something breaks the rules (fraud, bugs, attacks)
  • Understand Emergence - Watch how simple rules create complex behaviors
  • Validate Invariants - Ensure economic/trust rules are never violated
  • Debug Systems - Visualize state transitions and find issues
  • Predict Behavior - Simulate "what if" scenarios before deploying

Conservation Laws (Invariants)

These are rules that must NEVER be broken. If any shows , something is seriously wrong:

LawWhat It Enforces
Mass ConservationTotal value can't appear/disappear - no money printing
Energy ConservationSystem activity is bounded - prevents runaway processes
Identity UniquenessNo duplicate IDs - prevents identity fraud
CausalityEffects follow causes - no time travel attacks
Trust BoundsTrust stays 0-100% - no impossible trust values
Non-Negative ValueNo negative balances - prevents debt exploits

  1. Generate Universe - Click "Galaxy (500+)" or "Small (30)" to create demo data

  3. Watch Conservation Laws - All should stay green
  4. Adjust Physics - Change gravity, repulsion to see different behaviors
  5. Load Real Data - (Owner only) Load actual platform users/services
